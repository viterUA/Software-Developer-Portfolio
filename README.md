# Software Developer Portfolio

Portfolio of **Mykhailo Hnylytskyi**, a Software Development graduate of Munster Technological
University, Ireland. It covers three years of university coursework and a final diploma project.
Each project has a description, its tech stack, a code snippet and, where possible, a live demo.

## What's inside

- **30 projects** from Year 1–3 plus the diploma project, searchable and filterable by technology,
  with a **Grid / List** layout switch.
- **Live demos:**
  - **Original coursework websites** (Mister Olympia, viter B&B, Who Wants to Be a Millionaire),
    opened full screen in a sandbox.
  - **PHP BANK:** a browser-only replica of a Laravel online-banking team project.
  - **14 interactive mini-demos:** short JavaScript re-creations of the core logic of the Java,
    Python, C# and PHP projects.
- **CV section** with experience, education and skills, plus a downloadable CV.

## Built with

Plain **HTML, CSS and JavaScript**: no frameworks, no build step, no dependencies.

## Security

- A strict Content Security Policy: the page runs only its own scripts and loads no third-party
  code.
- No inline scripts or styles.
- Each demo runs in a sandboxed iframe that can't reach the main page.
- On hosts that support it, `_headers` adds clickjacking protection, HSTS and a locked-down
  Permissions-Policy.

## Run it locally

```
python -m http.server 8000
```

Then open <http://localhost:8000>.
